Du PDF au Word, sans casser la mise en page

pdf2docx rend un document Word modifiable, avec les colonnes, les tableaux, les encadrés et les images à leur place. Les PDF scannés sont lus par OCR. Tout reste sur votre ordinateur.

Avant et après

Ce qui est conservé

Texte et typographie
Polices, tailles, gras, italique, exposants, soulignements, retours à la ligne de Word simulés pour que les lignes tombent aux mêmes endroits.
Colonnes
Vraies sections Word de deux colonnes ou plus, pas un tableau déguisé.
Tableaux
Avec bordures, sans bordures, cellules fusionnées, bordures différentes d'une cellule à l'autre.
Encadrés, cadres et formes
Fonds colorés, filets, cadres d'en-tête, formes courbes.
Images
Recadrées comme dans le PDF, transparence conservée, texte qui les contourne.
En-têtes et pieds de page
Vrais en-têtes Word, avec numéro de page automatique.
PDF scannés
Redressement de la page, reconnaissance du texte, tableaux retrouvés sur l'image.

Installer

Python 3.10 ou plus. Pour les PDF scannés, ajoutez Tesseract avec la langue française.

git clone https://github.com/YOUR-USER/pdf2docx.git
cd pdf2docx
python -m venv .venv
.venv\Scripts\activate        # Linux / macOS : source .venv/bin/activate
pip install .
pdf2docx-gui

Une page s'ouvre dans le navigateur : glissez vos PDF, téléchargez les fichiers Word.

Cette page est une vitrine : GitHub Pages ne peut pas exécuter Python. Le convertisseur tourne sur votre machine, et vos fichiers ne partent jamais sur Internet.
